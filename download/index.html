Install in three steps

  1. Get the APK. Download atom-<version>.apk from the latest release on your phone, or add Atom to Obtainium. When you open the file, Android may ask you to allow installs from your browser or file manager. Allow it for that app, then install.
  2. Add a model. Open Atom and paste an API key for a provider, sign in with a ChatGPT or Grok subscription, or download an on-device model. You can chat right away.
  3. Let it act (optional). Turn on Atom’s accessibility service so it can operate apps, and switch on the floating bubble. Android may grey out the accessibility switch for apps installed outside a store: open Atom’s App info, tap the ⋮ menu, choose Allow restricted settings, then try again.

How updates are verified

Atom checks for updates only when you open Settings → About or tap Check for updates. There are no background checks. When you tap Update, Atom:

  1. downloads the release’s checksum file, then the APK, only from github.com/namanwtf/atom/releases/download/, refusing anything larger than the size GitHub published;
  2. checks the APK’s SHA-256 against the published one;
  3. checks that the APK has the same package name, the same signing certificate as the app you have, and a higher version code;
  4. hands it to Android’s own installer, which asks you to confirm.

The optional on-device AI pack gets the same treatment: it comes only from the release for your exact version, must match its published SHA-256, and must carry the app’s own signing certificate before it is loaded.

Check an APK yourself

Compare the file’s hash with the .sha256 file on the release page:

sha256sum atom-*.apk

Then check who signed it with Android’s apksigner:

apksigner verify --print-certs atom-*.apk

The certificate’s SHA-256 digest must be:

D2:B8:3B:EC:14:AD:2B:0E:E6:A0:18:85:46:1A:0A:9D:BD:78:A4:B3:D3:74:D2:92:71:4D:E8:63:B4:7A:45:78

Release builds use the package name io.github.namanwtf.atom. Every Atom 4 release updates in place over the previous one.

Device requirements

Android14 or newer
CPUARM64 (arm64-v8a)
App sizeAbout 7.2 MB
On-device AI packOptional, about 32 MB, plus the model you choose (from about 600 MB)
RootNot needed. Root (Magisk, KernelSU or APatch), Shizuku or the LSPosed module unlock deeper device control
LanguageEnglish interface

Chat, memory, skills, MCP, subagents, scheduled tasks, the terminal, Linux, files and the web need nothing beyond the app. CI tests every change on Android emulators; battery use on real phones isn’t measured yet.

Permissions overview

Nothing is asked at first launch. Atom asks for each permission the first time a feature needs it, with one sentence saying why, and works without the optional ones.

FeatureWhat it needs
Chat, memory, skills, MCP, subagents, schedules, terminal, Linux, webNothing beyond the app
Operating apps, reading the screenAccessibility service
Floating bubble and run capsuleDisplay over other apps
Personal context (notifications, codes, calendar, contacts, files, location)That source’s own Android permission, asked on first use
Voice and “Hey Atom”Microphone, asked when you tap the mic or switch the wake word on
In-app updatesInstall unknown apps, asked only when you tap Install on an update
Deeper device control (freeze apps, system settings, logs)Root or Shizuku
Hidden-screen tasks, system assistant extrasRoot or the LSPosed module

The complete list, with what uses each permission and exactly when it is asked, is in docs/PERMISSIONS.md.
