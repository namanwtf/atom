Questions, answered.

Everything people ask about Atom, the AI agent for Android: models, privacy, safety, battery and updates.

The basics

What is Atom?

Atom is a free, open-source AI agent for Android. It reads the screen and operates your apps, uses your phone’s context when you allow it, runs a real Linux terminal, works on a schedule, and uses the model you choose, including models that run fully offline on the phone. See all features.

Is Atom free?

Yes. Atom is free software under the GNU GPL v3.0 or later, with no ads, no paid tier and no account. You pay your model provider, use a subscription you already have, or run a free on-device model.

Which phones does it run on?

ARM64 phones with Android 14 or newer. The APK is about 7.2 MB. The interface is in English.

Do I need root?

No. Root, Shizuku or the LSPosed module only add extras, such as freezing apps, protected settings, logs, or running tasks on a hidden screen. Linux runs without root in PRoot.

Why isn’t Atom on Google Play?

That’s deliberate. Atom ships from GitHub Releases and Obtainium, with an in-app updater that checks every update’s SHA-256 and signing certificate. An IzzyOnDroid listing is coming, and F-Droid later. See Download.

Models

Which AI models can I use?

14 providers are built in: OpenAI, Anthropic, Gemini (AI Studio and Vertex AI), DeepSeek, Qwen (Alibaba Bailian), Kimi, MiMo, MiniMax, StepFun, SiliconFlow, OpenRouter, xAI, Groq and Mistral. You can also add any OpenAI- or Anthropic-compatible endpoint, such as llama.cpp or Ollama on your own computer. How to set one up.

Can Atom run without the internet?

Yes. Download the optional on-device AI pack (about 32 MB) and a model, and Atom runs it on the phone with LiteRT-LM or llama.cpp. Nothing leaves the phone. Offline guide.

Can I use my ChatGPT or Grok subscription?

Yes, by signing in with your ChatGPT or Grok account instead of an API key. It’s experimental: it reuses the vendor’s own app login, which the vendor may flag or limit your account for. An API key is the recommended way.

How good are on-device models as agents?

Small on-device models handle chat, quick answers and simple tool calls well. For long, multi-step app tasks, a strong cloud model does much better.

Privacy and safety

Where does my data go?

It stays on your phone, except the messages sent to the model provider you choose (none with an on-device model), web searches to the search engine you set, and an update check to GitHub when you open About. There is no Atom server. Read the privacy policy.

Does Atom collect analytics or telemetry?

No. There is no telemetry, no analytics, no crash reporting and no account. The developer receives no data from the app.

How are my API keys stored?

Encrypted, with a key held in the Android Keystore that never leaves the phone. Android’s cloud backup is turned off for Atom.

Can Atom do things without asking?

Shell commands always ask first, with one tap to allow all commands for the rest of that task; commands that look destructive still ask. Sensitive actions ask too, and you can turn on “ask before taps and typing” to approve every step. Every tool has its own switch, and Stop always works.

What happens on the lock screen?

Over the lock screen Atom only shows that a task finished. To see the result or approve anything, you unlock first.

Can I undo what Atom changed?

Yes. Every change Atom makes to the device goes into an undo history, so you can see what changed and put it back.

Using Atom

Will it drain my battery?

Atom works only when you give it something to do. Scheduled tasks wake it briefly, on-device models unload after 5 minutes idle, and animations stop when it’s idle. Battery use on real phones isn’t measured yet, because CI tests run on emulators.

Can it work in the background?

Yes. Scheduled tasks and phone-event automations run in the background and report back by notification, and long tasks keep going with the screen off. Automation guide.

Can it operate every app?

Most. App control goes through Android’s accessibility service, which is slower than your thumb, and apps that hide their screens from accessibility can’t be operated.

Does it support other languages?

The interface is English only for now. Models may answer in other languages, depending on the model.

How do updates work?

Open Settings → About or tap Check for updates. Atom downloads the new APK from GitHub, checks its SHA-256 and signing certificate, then hands it to Android’s installer. Obtainium can also keep Atom up to date. Details.

How do I report a bug or ask for a feature?

Open an issue on GitHub. From 4.0.6, Report a problem in the app builds a report with keys, tokens and personal data removed, for you to read and share.
