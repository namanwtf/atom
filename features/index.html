Everything Atom can do on your phone.

An AI agent for Android with real reach: it operates apps, reads your context when you allow it, runs Linux, works on a schedule and uses the model you choose.

It operates your apps, then checks.

Atom works through Android’s accessibility service. It reads what’s on the screen, then taps, types, swipes and scrolls like you would. Where a dedicated tool is faster and surer (Do Not Disturb, volume, brightness, alarms, timers, media, flashlight), it uses that tool instead.

After it acts, it looks again. A task is reported as done only when the screen or the setting shows it. If it can’t confirm something worked, it says so, and tells you what it saw.

  • Every step appears in the chat with its arguments and timing.
  • Long tasks keep going while they make progress, and Continue picks up a run that reached its step limit.
  • With the screen off, background work carries on; screen tasks wait for you to unlock.
  • With root or Shizuku it goes deeper: freezing apps, protected settings, logs.

A bubble over any app, and the assistant gesture.

The floating bubble sits over whatever you’re doing and remembers where you left it.

  • Tap for a mini chat that stays on top of the app.
  • Hold for quick actions: voice, chat, close.
  • Drag it anywhere on the screen.

You can also set Atom as the phone’s assistant. A long press of the power button then opens it, already knowing what’s on screen. That costs nothing in the background: no microphone, no service running.

A small run capsule shows a task’s progress while you use other apps, with Stop always one tap away.

Your context, one permission at a time.

Atom can use what your phone already knows, but only the part a task needs, and only after you allow it.

  • Notifications: what’s showing now and a 7-day history, for questions like “what did I miss?”
  • One-time codes from your messages.
  • Calendar: read, create, change and delete events.
  • Contacts, files and location.

Nothing is asked at first launch. Each permission is asked once, the moment a feature first needs it, with one sentence saying why. Say no and that feature turns off and says so; Atom doesn’t keep asking. The full permission list shows what uses each one.

A terminal and real Linux, no root needed.

Atom has a full terminal with several sessions: the Android shell, a root shell if you have root, and Linux.

Linux runs on the phone: Alpine or Debian. Standard mode uses PRoot and needs no root. Root mode uses a chroot in its own mount namespace, at native speed.

  • Base tools: git, curl, jq, ripgrep, fd, ssh, sqlite3, nano and more.
  • On request: Python (with uv), Node.js and npm, an OpenSSH server, and APK analysis tools.
  • Every download is checked: distro packages by their signatures, the rest against published SHA-256 sums.
  • Background commands keep running and notify you when they finish.

The agent uses all of this too: it writes code, runs it, reads the errors and fixes them. Read the Linux guide.

Schedules and automations.

Scheduled tasks run a request on a schedule, like “weekdays 07:45” or “every 2h”, and report back by notification. Each can use its own model and its own set of capabilities, and you choose whether it notifies every run, only on change, or silently.

Automations react to the phone: charger connected, battery level, screen on, unlocked, Wi-Fi or Bluetooth connected, headphones, Do Not Disturb or airplane mode changes, arriving at or leaving a place, a notification from an app, an app opened, or boot.

Describe one in a sentence and Atom builds it once into a trigger, conditions and steps. No model runs when the event fires, unless a step asks for one.

In 4.0.6: ready-made routines (Morning brief, Price watch, Weekly phone cleanup, Evening wrap-up). Read the automation guide.

Any model you like.

14 providers built in: OpenAI, Anthropic, Gemini (AI Studio and Vertex AI), DeepSeek, Qwen (Alibaba Bailian), Kimi, MiMo, MiniMax, StepFun, SiliconFlow, OpenRouter, xAI, Groq and Mistral.

  • Anything compatible: any OpenAI- or Anthropic-compatible endpoint, including llama.cpp or Ollama on your own computer, plus the models.dev catalog.
  • Subscriptions: sign in with a ChatGPT or Grok account instead of an API key (experimental; an API key is the recommended way).
  • Per conversation: pick the model and the reasoning effort, from Off to Max, limited to what the model supports.
  • Per job: separate models for the floating assistant, subagents, titles and scheduled tasks.

Set up your own model.

Fully offline, on the phone.

The app stays small (7 MB) because on-device AI is an optional pack of about 32 MB, downloaded only from Atom’s own GitHub release and checked against its published SHA-256 and the app’s signing key.

With the pack, Atom runs models on the phone with LiteRT-LM (GPU accelerated) and llama.cpp (GGUF). One tap downloads a recommended model such as Qwen3 0.6B or Gemma 4 E2B and sets it up; you can also add any .litertlm or .gguf file from a link.

The pack also powers the on-device “Hey Atom” wake word. If the phone gets hot or the battery runs low, on-device inference pauses, and a cloud fallback takes over only if you set one.

Read the offline guide.

Memory, skills, MCP and more.

  • Memory you can read and edit: one Markdown file, kept up to date by Atom, with a core section sent with every message.
  • Skills: instruction packs installed from any public GitHub repository or a ZIP.
  • MCP servers over Streamable HTTP, with a switch for each tool. MCP guide.
  • Subagents: explore, coder and plan, plus your own, working with their own context.
  • Voice: dictation, spoken answers and an on-device “Hey Atom” wake word (needs the pack).
  • Agent browser you can take over, plus web search and page reading.
  • Image generation and editing with the image service you choose.

You stay in charge.

  • Shell commands ask first, with one tap to allow all commands for the rest of that task. Commands that look destructive still ask.
  • Optional “ask before taps and typing” to approve every step.
  • Stop always works: from the chat, the run capsule or the notification.
  • Undo history: every change Atom makes to the device is recorded, with one-tap undo.
  • Locked means locked: over the lock screen Atom only shows that a task finished. To approve anything, you unlock first.
  • Every tool has its own switch, and it takes effect even mid-task.

Private by design.

No telemetry, no analytics, no account and no Atom server. API keys are encrypted with a key held in the Android Keystore. Messages go only to the model provider you pick, or nowhere with on-device models. Web searches go to the search engine you set. The only automatic call to GitHub is the update check, when you open About or tap Check for updates.
