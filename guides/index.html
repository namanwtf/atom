Guides for an AI agent on Android.

Plain how-tos for the things people search for most: offline AI, your own models, MCP, Linux without root and automation. Each one matches how Atom works today.

  • Run AI fully offline on your Android phone

    Download the 32 MB on-device pack, pick a model that fits your RAM, and chat or run simple tasks with no internet at all.

    6 min read

  • Use your own model or a ChatGPT or Grok subscription on Android

    Add an API key for any of 14 built-in providers, point Atom at your own OpenAI- or Anthropic-compatible server, or sign in with a subscription.

    7 min read

  • Use MCP servers on Android

    Connect a remote or local MCP server over Streamable HTTP and switch on exactly the tools Atom may call.

    5 min read

  • Linux on Android without root

    Install Alpine or Debian in PRoot, open a real terminal, and let the agent run git, curl, Python or Node for you.

    6 min read

  • Automate your Android phone with plain sentences

    Turn one sentence into a scheduled task or a phone-event automation that runs in the background and reports back.

    6 min read
