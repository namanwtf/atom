Linux on Android without root

Atom installs a real Alpine or Debian system on your phone. Without root it runs in PRoot; with root it can use a chroot at native speed. You get a terminal, the usual tools, and an agent that can use them.

Updated 27 November 20266 min readWorks with Atom 4.0.5 and later

Install it

  1. Open the Linux environment. Go to Settings → Linux environment.
  2. Choose a distribution. Alpine is the smallest. Debian is a glibc system with broader software compatibility. To switch later, you uninstall the current system first.
  3. Keep Standard mode. Execution mode: Standard · PRoot needs no root and keeps everything private to Atom.
  4. Install the base. Tap Install base. Atom installs the system, then the base tools (about 70 MB on Alpine, 180 MB on Debian).
  5. Open a terminal. Go to Terminal and start a Linux session. Android shell and root shell sessions are there too.

What’s included, and what you can add

The base tools include git, curl, jq, rg (ripgrep), fd, ssh, sqlite3, file, xz, unzip, less, nano and htop. On request, Atom adds:

BundleWhat’s in itSize

Every download is checked: distro packages by their apk or apt signatures, GitHub release assets against the SHA-256 GitHub publishes, and Node.js against its release checksums. You can install anything else with apk add or apt install as usual.

The terminal

  • Several sessions side by side: Android shell, root shell (if you have root) and Linux.
  • Console mode is a full terminal with an extra key row (Esc, Tab, Ctrl, Alt, arrows). Simple mode gives you a command box with copy and reuse buttons.
  • Pinch to change the text size.

Files

Your projects live in /workspace, which you can browse, import to and export from under Workspace & files. Shared folders connect Linux to folders on the phone. To see /sdcard from Linux, Atom asks for All files access the first time it’s needed.

Let the agent use it

Ask in plain words: Clone this repo, run its tests and tell me why they fail. Atom writes and runs the commands, reads the output and fixes what it can. Shell commands ask first; one tap allows all commands for the rest of that task, and commands that look destructive still ask. Long-running commands and daemons can keep going under Background tasks, and you get a notification when they finish.

With root: chroot mode

On a rooted phone, choose Root mode · chroot. Linux then runs in its own mount namespace at native speed. Files created in Root mode belong to root and may be read-only if you switch back to Standard mode.

Honest limits. PRoot is slower than native, and some software won’t run in it, especially anything that needs its own kernel features, such as containers or system services. Upgrade and Repair in the Linux settings update packages or fix a half-configured system.
