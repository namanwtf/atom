Use MCP servers on Android

The Model Context Protocol (MCP) is a standard way for services to offer tools to AI agents. Atom connects to MCP servers from your phone, and every tool stays off until you switch it on.

Updated 27 November 20265 min readWorks with Atom 4.0.5 and later

How Atom talks to MCP servers

Atom connects over Streamable HTTP, the MCP transport that works over a URL (it reads both JSON and SSE replies). It doesn’t launch servers as local processes, so the server needs an address Atom can reach:

  • a remote server on the internet (https://);
  • a server on your home network, such as a self-hosted service with an MCP endpoint;
  • a server running in Atom’s own Linux environment, at http://127.0.0.1:PORT.

A connection opens only for one piece of work, such as reading the tool list or making a call, and closes right after. Nothing stays connected in the background.

Add a server

  1. Open MCP servers. Go to Settings → MCP servers (under Context & extensions).
  2. Add the server. Tap Add server and fill in a name, the server URL (for example https://example.com/mcp) and, if the server expects one, a bearer token. The token is stored encrypted.
  3. Let Atom read the tools. Tap Add. Atom connects once and reads the tool list first, so a server is saved only if it answers.
  4. Switch on tools. Every tool starts off. Turn on the ones you want, or all of them at once. When a tool isn’t marked read-only, Atom warns that it may change data or call an external service.
  5. Use it. Ask Atom in plain words. Tools that aren’t read-only still ask you before each use.

Keep control

  • Enable server off hides all of that server’s tools from Atom at once.
  • Refresh tools reads the list again. Tools you enabled stay enabled if they still exist; new tools start off.
  • Authentication changes or removes the bearer token.
  • Very large catalogs are cut at 2,048 tools or 64 pages, and Atom tells you when that happens.

Run an MCP server on the phone

Because Atom has a real Linux environment, you can run a server right on the phone:

  1. Install Linux and the runtime the server needs (Python or Node.js). See Linux on Android without root.
  2. Start the server with its HTTP transport, listening on 127.0.0.1. The server’s own README says which option turns HTTP on.
  3. Keep it running from Background tasks in the Linux environment settings.
  4. Add it in Atom with the URL it prints, such as http://127.0.0.1:8000/mcp.

Plain HTTP is fine on the phone and your home network. Atom allows http:// for addresses you type, such as 127.0.0.1 or a LAN IP. Use https:// for anything on the internet.
