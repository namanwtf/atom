Use your own model or a ChatGPT or Grok subscription on Android

ATOM doesn’t come with a model of its own. You bring one: an API key for a provider, your own server, a subscription you already pay for, or an on-device model. Here are the three online options.

Updated 27 November 20267 min readWorks with ATOM 4.0.5 and later

To use your own model on Android, open ATOM’s Settings → LLM providers and paste an API key, add your own OpenAI- or Anthropic-compatible server, or sign in with a ChatGPT or Grok account.

Option 1: an API key for a built-in provider

ATOM has 14 providers built in: OpenAI, Anthropic, Gemini (AI Studio and Vertex AI), DeepSeek, Qwen (Alibaba Bailian), Kimi, MiMo, MiniMax, StepFun, SiliconFlow, OpenRouter, xAI, Groq and Mistral.

  1. Open the provider. Go to Settings → LLM providers and tap the provider. Get a key opens the provider’s own key page.
  2. Paste the key. Keys are encrypted with a key held in the Android Keystore, so they never leave the phone in readable form.
  3. Fetch models and test. Fetch models reads the provider’s model list. Test connection sends one small request and shows the reply and the time it took.
  4. Pick it. Set it as the default model for new conversations, or switch per conversation from the model picker.

Option 2: your own server, or any compatible API

Tap Add new provider and choose:

  • Add OpenAI-compatible provider, with Chat Completions or Responses API as the endpoint mode;
  • Add Anthropic provider, for the Anthropic Messages API or compatible servers;
  • Add Gemini, for Google AI Studio or Vertex AI;
  • Add from models.dev, to browse the community catalog and pick models.

Enter the base URL and, if the server needs one, a key. For a server on your computer, use its address on your home network:

ServerBase URL example
llama.cpp (llama-server)http://192.168.1.20:8080/v1
Ollamahttp://192.168.1.20:11434/v1
A server inside ATOM’s Linux environmenthttp://127.0.0.1:PORT/v1

Make sure the server listens on your network, not only on its own machine: start llama-server with --host 0.0.0.0, or set OLLAMA_HOST=0.0.0.0 for Ollama. Plain http:// works for addresses you type yourself, such as a local or home-network server; all built-in cloud providers use HTTPS. On Android releases that gate local network access, ATOM asks for that permission.

Each provider also takes custom headers (for example a User-Agent) and an extra request body, a JSON object merged into every request. Authentication headers stay managed by ATOM.

Option 3: sign in with a ChatGPT or Grok subscription

If you already pay for ChatGPT or Grok, you can use that plan instead of an API key.

  • ChatGPT: open Settings → LLM providers → OpenAI, set Authentication to ChatGPT account and tap Sign in with ChatGPT. Finish in your browser, then come back. Requests use your subscription quota; Sync models lists the models your plan offers, and Manage usage opens your usage page.
  • Grok: open Settings → LLM providers → xAI, set Authentication to Grok account and tap Sign in with Grok. ATOM shows a code: open the sign-in page, enter the code, and you’re done.

Experimental, and a real risk to your account. Subscription sign-in reuses the vendor’s own app login, which the vendor doesn’t offer to other apps and may flag or limit your account for. An API key is the recommended way. Sign-in tokens are encrypted on the phone and never included in backups.

Make the most of it

  • Reasoning effort is set per conversation, from Off to Max, limited to what the model supports.
  • Models for specific jobs: pick separate models for the floating assistant, subagents, conversation titles and scheduled tasks. A small, fast model works well for titles.
  • Cloud fallback: if you use an on-device model, a cloud model can take over when the phone is hot or the battery is low. See running AI offline.

Get ATOM

ATOM is free and open source. Download the APK from GitHub Releases or add it to Obtainium; see the download page for install steps and how updates are verified.
