Run AI fully offline on your Android phone

ATOM can run language models on the phone itself, with LiteRT-LM and llama.cpp. After the download there is no account, no API key and no internet involved. Here is how to set it up, and what small models can and can’t do.

Updated 27 November 20266 min readWorks with ATOM 4.0.5 and later

To run AI offline on Android, install ATOM, download its free 32 MB on-device pack and one model, and the model then runs on your phone with no internet.

The ATOM app itself carries no on-device AI, which is why it is only 7 MB. The engines live in an optional pack you download once. With it, models run entirely on your phone.

What you need

  • An ARM64 phone with Android 14 or newer.
  • Free RAM for the model: about 2 GB for the smallest one, 4 to 8 GB for the larger ones.
  • Storage for the model file: from about 600 MB up to 4.7 GB.
  • A connection for the one-time downloads. After that, none.

Set it up

  1. Install ATOM. Get the APK from the download page (GitHub Releases or Obtainium).
  2. Download the on-device AI pack. Open Settings → LLM providers → On-device models. At the top you’ll see On-device AI (optional, about 32 MB). Tap Download. The pack comes only from ATOM’s own GitHub release for your exact version, and ATOM checks it against the published SHA-256 and the app’s own signing key before loading it.
  3. Pick a model. The Recommended list shows each model’s download size, the RAM it needs, its licence and whether it understands images. If a model needs more RAM than your phone has, ATOM says so before you download. Turn on Download on Wi-Fi only to save mobile data.
  4. Download it and use it. Tap Download. The file is checked against its SHA-256 and set up. Tap Use this model, or choose it in any conversation’s model picker, where it carries an on-device badge.
  5. Test it offline. Turn on airplane mode and ask a question. The reply is generated on the phone.

Which model to pick

LiteRT-LM models run on the GPU and use the least battery. GGUF models run with llama.cpp on the CPU (or GPU if you choose it).

Gemma 4 E2B is a good everyday pick if your phone has the RAM. Qwen3 0.6B is the one to try first on a smaller phone.

Use your own model file

Under Add from a link, paste a Hugging Face link or a direct URL to a .litertlm or .gguf file. Some models, such as Gemma 3n, are gated: accept the licence on Hugging Face, then add a read token in the Hugging Face section. The token is stored encrypted.

Hardware, heat and battery

  • Hardware: Auto picks the NPU or GPU when the model supports it. GGUF models use the CPU unless you choose GPU.
  • Memory: a model is unloaded after 5 minutes idle, or sooner if Android needs the memory.
  • Heat and battery: when the phone is hot, Battery Saver is on or the battery is low, on-device inference pauses. If you set a cloud fallback, it takes over; if you don’t, nothing leaves the phone.

What to expect

Small on-device models are good at chat, rewriting, quick answers and simple tool calls such as “Turn on Do Not Disturb”. ATOM’s own release tests run on a 3B model. For long, multi-step app tasks, a strong cloud model does much better. Speed depends on your phone’s chip.

Also offline with the pack: the “Hey ATOM” wake word. It listens only while the screen is on or the phone is charging, and pauses on Battery Saver, heat, low battery and calls. Web search and page reading still need a connection, of course.

Get ATOM

ATOM is free and open source. Download the APK from GitHub Releases or add it to Obtainium; see the download page for install steps and how updates are verified.
