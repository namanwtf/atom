How app control works on Android

ATOM uses Android’s accessibility service to read the screen and to tap, type, swipe and scroll. For Do Not Disturb, volume, brightness, alarms, timers, media and the flashlight it uses direct tools, which are faster and more reliable. Each step shows in the chat with its arguments and time, Stop works at any point, and every device change goes into an undo history. Apps that hide their screens from accessibility can’t be operated. Scheduled tasks and phone-event automations run in the background and report back. You describe them in a sentence.

What else the workbench does

The terminal has sessions for the Android shell, a root shell and Linux. Python and Node.js install on request, every download is checked against signatures or published SHA-256 sums, and long commands keep running in the background. The agent uses the same tools: it writes code, runs it and fixes the errors. Automations react to the charger, battery, Wi-Fi, Bluetooth, a place, a notification or an app opening, and no model runs when they fire unless a step needs one.

14 providers are built in. ATOM also talks to any OpenAI- or Anthropic-compatible server, signs in with a ChatGPT or Grok subscription, connects to MCP servers, and runs models on the phone with an optional 32 MB pack.

Offline models, subscriptions and MCP

The on-device pack adds LiteRT-LM and llama.cpp. One tap downloads a model such as Qwen3 0.6B or Gemma 4 E2B, and nothing leaves the phone. ChatGPT and Grok sign-in is experimental; an API key is the recommended way. MCP servers connect over Streamable HTTP, and every tool stays off until you switch it on.

What leaves your phone.

No telemetry, no analytics, no account and no ATOM server.

Stays on the phone

  • Chats, memory, files, schedules and the Linux environment
  • API keys, encrypted with a key held in the Android Keystore
  • Notifications, messages, calendar and other context ATOM reads

Leaves it

  • Your messages, to the model provider you pick. Nothing, with an on-device model.
  • Web searches, to the search engine you set: DuckDuckGo, Bing or Mojeek by default.
  • An update check to GitHub, only when you open About or tap Check for updates.
